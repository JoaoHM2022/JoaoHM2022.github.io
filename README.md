Controle de finanças totalmente Offline 
Desenvolvido para controle financeiro, sem a necessidade de fornecimento de dados bancários e pessoais a terceiros.

Como funciona:

Armazenamento dos dados por meio de LocalStorage, permitindo usar a memória do próprio navegador para salvar os dados.
Em caso de limpeza dos dados do navegador ou de acesso em outro dispositivo, foi implementado método de salvamento de dados em arquivos JSON, o qual é guardado localmente na sua máquina.
Nada é armazenado em banco de dados e ninguém terá acesso sem os seus arquivos, por isso proteja-os bem.



Funcionalidades:

* Definir meta de gastos por categorias;
* registro de cartões, limites e respectivos bancos;
* definir uma meta de investimento em valor perante a sua renda mensal;
* Registro de todos os gastos selecionáveis por bancos;
* Separação de gastos por mês;
* Campo para criação de categorias de gastos e registro de qualquer banco.


OBS:

Todas as categorias de gastos podem ser criadas de maneira personalizada, não há bancos pré-selecionados na lista, também são adicionadas por cada pessoa de maneira personalizada.

Funciona tanto em Desktop quanto para Mobile.
